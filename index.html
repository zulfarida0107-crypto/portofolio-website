CuitBox (Photobox Platform) ✦

"A self-service photo booth system where customers book online and take photos at a kiosk, while owners manage everything from one dashboard."

hub System Architecture & Engineering Deliverables

  • › Relational Database & APIs: Designed normalized relational database architecture & RESTful endpoints bridging the online booking website and the standalone desktop kiosk.
  • › Comprehensive Admin Dashboard: Slot reservation management, real-time slot scheduling, dynamic tiered pricing, booth machine telemetry, and automated financial report generation in Excel, CSV, and PDF formats.
  • › Desktop Kiosk Application: Interactive touch-screen capture UI with countdown timers, template selection, and automatic session cleanup.
  • › Security & Authentication: Role-Based Access Control (RBAC), session tokens, and secure transaction validation.
  • › 3rd Party Integrations: Midtrans QRIS payment gateway with real-time webhooks, Google Drive OAuth API for automated cloud photo archiving, and SMTP transactional emails with download links.
build Hardest Engineering Challenge Solved

Problem: Getting DSLR and webcam live-view streams to render stably on low-latency kiosk displays without frame jitter, while concurrently saving high-res RAW frames and recording behind-the-scenes video in the background.
Solution: Implemented hardware driver abstraction layers and dedicated multithreaded capture pipelines using Python OpenCV and native device bindings, guaranteeing zero UI freeze during disk I/O.
